A tiny paper-trading bot for hourly Solana prices: MACD trend with a CCI dip — buy the dip while the trend is up, take profit at +2%, cut the loss at -2%. Backtested +$139.25 net PnL on the dev window (22 trades, 1.6% max drawdown), beating buy-and-hold (-$869.34) and every house baseline.

## Run it

```sh
node main.ts
```
